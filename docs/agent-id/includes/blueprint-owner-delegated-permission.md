# Purpose:
# To clarify who can create agent identity blueprints.
---
> [!NOTE]
> Owners of an agent identity blueprint or agent identity blueprint principal can create agent identities for that blueprint without a Microsoft Entra Agent ID role. Managed fleet creation experiences assign the creator as an owner of the blueprint and its associated principal. For programmatic creation, follow the procedure's owner assignments explicitly. Single-instance blueprints don't have a blueprint principal.
