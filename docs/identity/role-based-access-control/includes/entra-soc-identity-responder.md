This is a [privileged role](../privileged-roles-permissions.md). Assign the Entra SOC Identity Responder role to users who need to do the following tasks from the Microsoft Defender portal:

- Disable and enable user accounts during active security incidents
- Revoke active sign-in sessions for compromised users by invalidating their refresh tokens
- Reset passwords for compromised user accounts
