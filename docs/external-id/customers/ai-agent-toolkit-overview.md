# Microsoft Entra External ID agent toolkit overview

The Microsoft Entra External ID agent toolkit is a collection of skills for AI coding agents that help you work on Microsoft Entra External ID apps. Choose a task-specific skill to help onboard an app or migrate an existing native authentication implementation.
